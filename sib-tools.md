# SIB Tools for Learning SPARQL

*Presenters: Ana-Claudia Sima, Vincent Emonet — 15–20 min*

An overview of tools developed and supported by the SIB Swiss Institute of
Bioinformatics that support SPARQL learning and query documentation:

- **SPARQL Guidelines** — best practices for writing and documenting queries
- **sparql-examples** — a standardised metadata format for reusable SPARQL queries with SHACL-based validation
- **SPARQL Playground** — an interactive environment for exploring and experimenting with SPARQL queries
- **SPARQL-Fest** — a front-end platform that aggregates workshop outputs and showcases participant-contributed queries

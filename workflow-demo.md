# Demonstration of the Complete Workflow

*Presenter: Andra Waagmeester — 15–20 min*

A complete end-to-end walkthrough of the tutorial workflow:

1. Identify a question answerable via SPARQL
2. Locate relevant RDF resources and explore namespaces, classes, and properties
3. Draft and refine a SPARQL query
4. Document it using the sparql-examples format
5. Publish it on GitHub
6. Visualise it through the SPARQL-Fest interface
